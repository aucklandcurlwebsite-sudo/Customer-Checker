CUSTOMER CHECKER FOR MIRO

Theresa's customer checker

A working customer form, payment totals and a live pie chart, inside your Miro board.

Try the preview

The preview uses temporary sample records. Live customer data stays in Miro.

Install in Miro
  1. Create a Web SDK app in your Miro developer dashboard.
  2. Set its App URL to this page's address.
  3. Enable boards:read and boards:write, then install it for the team containing Acc Board.
  4. Open Acc Board and select Customer Checker from the Apps toolbar.

The interface must be hosted at an HTTPS address Miro can load. This app saves each customer as a Miro app card; it does not send customer records to this host.
